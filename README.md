# Onshore SDK for Android

Secure collect and reveal views for Android (Jetpack Compose and Views). The app holds no credentials: your server mints a single-use client token.

## Install

Not on Maven Central yet. Build the library and add the AAR to your app:

```sh
git clone https://github.com/Onshore-HQ/onshore-android && cd onshore-android
./gradlew assembleRelease   # build/outputs/aar/
```

## Documentation

Full reference, with every method, parameter, return value and error: https://docs.onshorevault.com/developers/sdks/android/
